<p><b>关于本应用</b></p>  
<p>轻听是一款聚合网易云音乐、QQ 音乐、酷我音乐、酷狗音乐四大平台资源的移动端音乐播放器，支持 Android 与 Windows（近期准备内测）。用音乐连接每一刻。本应用为个人开发作品，音乐数据来自各平台公开接口，仅供学习交流，请勿用于商业用途，尊重各平台版权。</p>  
<p><b>主要功能</b></p>  
<ul>  
<li><b>多平台聚合</b>：搜索、歌单广场、排行榜、每日推荐、热门榜单、新歌速递、歌手页、热门搜索词全覆盖，四平台随手切换。</li>  
<li><b>播放与歌词</b>：原生后台播放（锁屏、后台持续播放），唱片机动画 + 滚动歌词；多种音质（标准 / 高品 / 无损）；播放倍速、播放队列、下一首播放。</li>  
<li><b>桌面歌词</b>：系统悬浮窗歌词，逐行跟随、可拖动、可锁定（锁定时点击穿透）；字号 / 颜色 / 字体可调并即时生效。</li>  
<li><b>在线缓存与下载</b>：在线播放边播边缓存（上限可调），重复播放不走网络；歌曲可下载离线播放，下载音质可选，支持后台下载。</li>  
<li><b>本地音乐</b>：扫描手机内歌曲（全盘 / 文件夹两种方式，可设最小文件大小过滤），与最近播放统一管理。</li>  
<li><b>收藏与同步</b>：收藏歌曲与歌单、自建歌单，登录后自动与服务器同步，多设备不丢失；断网收藏自动暂存、联网补推。</li>  
<li><b>账号与个人中心</b>：邮箱 / 用户名登录，邮箱验证码找回密码，签到积分，编辑个人资料。</li>  
<li><b>外观与皮肤</b>：明暗模式、Linen / Graphite / Aurora 预置皮肤、自定义背景，宽屏设备自动切宽屏布局。</li>  
<li><b>听歌统计</b>：累计播放、收藏、活跃天数、最常播放与最爱歌手。该部分仅保留在本地，不同步。</li>  
<li><b>应用服务</b>：启动自动检查更新、应用公告、消息中心、意见反馈、关于页。</li>  
<li><b>音源包热更新</b>：播放地址、歌词、封面等解析逻辑以「音源包」形式热更新，接口失效无需重装即可修复。应用不内置音源包：在线搜索与播放前需先在设置页「音源包」安装（检查更新下载官方包，或粘贴自备的 https 直链安装自定义包）；未安装时首页会显示安装引导，本地音乐播放不受影响。</li>  
</ul>  
<p><b>常见问题</b></p>  
<ul>  
<li><b>为什么播放的不是原曲？</b>本应用通过换源机制从各平台公开接口取播放地址，数据并非官方授权、也不保证准确，可能出现翻唱、Live、串曲或不同平台版本，属正常现象。</li>  
<li><b>为什么搜到的歌曲点不开或突然失败？</b>接口随时可能被上游调整或限制。遇到失败可换一首、切换音源，或到设置页「音源包」检查更新；若从未安装过音源包（首页有「未安装音源包」提示），请先「检查更新」或「从链接安装」。</li>  
<li><b>为什么显示无损却只有几 MB？</b>音质取决于上游线路，部分线路实际音质与标称不符；现已尽量优先选择可用的高音质来源，但仍无法百分百保证。</li>  
<li><b>为什么封面 / 歌词偶尔缺失或对不上？</b>封面与歌词同样来自各平台公开接口，可能出现缺失、错位或有延迟。</li>  
<li><b>为什么有的歌播放会卡顿或中断？</b>音源线路稳定性不一，个别歌曲的可用线路较少，失败时应用会自动尝试其它来源或跳到下一首。</li>  
<li><b>歌曲必须联网吗？</b>在线播放需联网；已播过的歌曲会边播边缓存，下载到本地的歌曲可离线播放。</li>  
<li><b>桌面歌词开了没反应？</b>需先授予「悬浮窗 / 显示在其他应用上层」权限，按提示在系统设置中开启即可。</li>  
<li><b>为什么桌面歌词每次启动都是关闭的？</b>该开关为运行期状态，每次启动默认关闭，需要时手动开启。</li>  
<li><b>为什么本地音乐删不掉文件？</b>删除第三方公共媒体文件需授予「所有文件访问」权限，应用内会引导开启。</li>  
<li><b>换手机后收藏还在吗？</b>登录同一账号会自动同步；断网时的收藏会暂存，联网后自动补推。</li>  
<li><b>提示更新要不要装？</b>建议更新，新版本会修复失效的接口与已知问题。</li>  
<li><b>上传头像为什么一直失败？</b>头像上传接口使用的第三方接口，存在稳定性和额度限制，如果上传失败请间隔一段时间重试。为了提高可用性，每天每人最多上传2次头像。</li>  
<li><b>为什么没有批量功能？</b>批量下载、收藏等对服务器压力很大，只是个垃圾的个人服务器，无法承受这么大的压力，故没有计划支持。</li>  
</ul>  
<p><b>已知不足</b></p>  
<ul>  
<li>音源接口非官方授权，稳定性与准确性受上游影响，无法承诺长期可用。</li>  
<li>部分歌曲因版权或线路限制可能无法播放，需依赖其它来源或下载的本地文件。</li>  
<li>封面、歌词的完整度与准确度依赖上游，个别歌曲可能缺失或与音频不同步。</li>  
<li>桌面歌词、本地文件删除等功能依赖系统权限，不同厂商机型（vivo / 小米 / OPPO 等）入口位置有差异。</li>  
<li>鸿蒙系统暂时没有单独适配。</li>  
<li>应用仍在持续迭代，偶发的小问题欢迎通过「意见反馈」提交。</li>  
</ul>
